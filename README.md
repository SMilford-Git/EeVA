# EeVA — Ethical eValuation Agent

EeVA is an ethical deliberation support research project. This repository holds supporting research materials for EeVA publications, including use cases, prompts, workflow documentation and evaluation outputs.

## Research context

EeVA is a research prototype supporting ethical reflection across multiple philosophical frameworks. It is not a substitute for human ethical judgement or formal ethical review.
